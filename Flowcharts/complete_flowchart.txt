================================================================================

  ---- I-a.  Keyword path (score_with_keywords) --------------------------------

  +-----------------------------+
  |  score_with_keywords()      |
  |  no LLM, no cache           |
  +-----------------------------+
               |
               v
  For each key_point in expert_answer:

  +-----------------------------+
  |  _phrase_in_text()          |
  |  strip parentheticals       |
  |  split "/" for OR logic     |
  |  remove stop words          |
  |  60% significant-word match |
  |  bidirectional prefix check |
  +-----------------------------+
               |
        < found in text? >
        /                \
      YES                 NO
       |                   |
  matched_set           missed_set
       |
       v
  +-----------------------------+
  |  _compute_coverage_score()  |
  |  if rubric: weighted sum    |
  |  else: matched / total      |
  +-----------------------------+
               |
               v
  +-----------------------------+
  |  _determine_point_sources() |
  |  "recall" if phrase in      |
  |  recall_transcript, else    |
  |  "probe"                    |
  +-----------------------------+
               |
               v
  return { coverage_score, quality_score=0.0,
           score, matched_points, missed_points }


  ---- I-b.  LLM path (score_with_llm) ----------------------------------------

  +-----------------------------+
  |  score_with_llm()           |
  +-----------------------------+
               |
               v
  +-----------------------------+
  |  _extract_evidence()        |
  |  pre-pass: compress the     |
  |  transcript to per-KP       |
  |  evidence bullets           |
  |  cached_evaluative_call()   |---> [[ LLM API ]]
  |  (or fallback: clip(3000))  |     [[ SQLite cache ]]
  +-----------------------------+
               |
               v
  +-----------------------------+
  |  build grading prompt:      |
  |  key_points + weights +     |
  |  evidence + quality scale   |
  |  (Chi: 0=recall,            |
  |   1=elaborated, 2=mech.)    |
  +-----------------------------+
               |
               v
  +-----------------------------+
  |  cached_evaluative_call()   |
  +-----------------------------+
               |
        < SELF_CONSISTENCY_SCORING? >
        /                           \
      YES                            NO
       |                              |
       v                              v
  call LLM N times              call LLM once
  _aggregate_grading_           ---> [[ LLM API ]]
  samples() majority
  vote per key_point
       |                              |
       +-----------+------------------+
                   |
                   v
  +-----------------------------+
  |  _resolve_llm_matches_      |
  |  with_quotes()              |
  |  map raw LLM strings back   |
  |  to canonical key_point text|
  +-----------------------------+
               |
               v
  For each matched point:

  +-----------------------------+
  |  _quote_supported()         |
  |  normalize both strings     |
  |  exact substring check      |
  |  fuzzy: ratio >= 0.9        |
  |  window >= 8 chars          |
  +-----------------------------+
               |
        < grounded? >
        /            \
      YES              NO
       |                |
    keep             demote to missed
    match            log warning
       |
       v
  +-----------------------------+
  |  _find_narrative_           |
  |  contradictions()           |
  |  scan sentences for negation|
  |  patterns near matched text |
  +-----------------------------+
               |
        < contradicted? >
        /               \
      YES                NO
       |                  |
  demote to            keep
  missed               match
               |
               v
  +-----------------------------+
  |  _compute_coverage_score()  |
  |  _compute_quality_score()   |
  |    mean(quality_ratings)/2  |
  |  _compute_combined_score()  |
  |    cw*coverage + qw*quality |
  |    clamped to [0,1]         |
  +-----------------------------+
               |
               v
  return { coverage_score, quality_score, score,
           matched_points, missed_points,
           quality_ratings, point_sources,
           feedback, strengths, gaps }
